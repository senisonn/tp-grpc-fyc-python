# Python gRPC Examples

10 exemples progressifs pour maîtriser gRPC Python.

## Exemples

1. **simple-service.py** - Service minimal
2. **validation.py** - Validation des entrées
3. **error-handling.py** - Gestion d'erreurs
4. **logging-interceptor.py** - Intercepteur logging
5. **auth-interceptor.py** - Authentification JWT
6. **repository-pattern.py** - Repository avec PostgreSQL
7. **testing.py** - Tests pytest
8. **streaming.py** - Server streaming
9. **client.py** - Client gRPC
10. **decorators.py** - Décorateurs pour erreurs

## Usage

Chaque exemple est autonome et peut être copié-collé dans votre projet.
Adaptez selon vos besoins.

Voir les guides PDF pour plus de détails.
