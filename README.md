# gRPC Master Course

Complete hands-on course for mastering gRPC from fundamentals to production.

## 🎯 Course Overview

- 8 sequences covering gRPC fundamentals to advanced topics
- 16 hours of training material
- Hands-on labs and real-world project
- Python & JavaScript/React implementation

## 🚀 Quick Start

1. Clone this repository
2. Follow [setup guide](docs/setup-guide.md)
3. Start with [Sequence 1](src/sequence-01-introduction)

## 📚 Course Structure

1. [Sequence 1: Introduction and Fundamentals](src/sequence-01-introduction)
2. [Sequence 2: Protocol Buffers and HTTP/2](src/sequence-02-protocol-buffers)
3. [Sequence 3: Communication Models and Streaming](src/sequence-03-communication)
4. [Sequence 4: Security and Authentication](src/sequence-04-security)
5. [Sequence 5: Back-End Implementation](src/sequence-05-backend)
6. [Sequence 6: Front-End Integration (gRPC-Web)](src/sequence-06-frontend)
7. [Sequence 7: Red Thread Project - Chat Application](src/sequence-07-project)
8. [Sequence 8: Conclusion and Advanced Topics](src/sequence-08-conclusion)

- Node.js 18+
